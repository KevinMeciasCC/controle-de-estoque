# 📦 Sistema de Controle de Estoque

Aplicação web desenvolvida para gerenciar produtos e acompanhar o estoque de forma simples e organizada. Este projeto faz parte da minha jornada de aprendizado em Engenharia de Software, com foco em JavaScript, manipulação do DOM e persistência de dados no navegador.

## 🚀 Funcionalidades

- **Cadastro de produtos:** registro de nome, preço e quantidade.
- **Listagem de produtos:** exibição organizada em cartões.
- **Edição de produtos:** atualização de preço e quantidade.
- **Exclusão de produtos:** remoção de itens cadastrados.
- **Pesquisa por nome:** filtragem dos produtos em tempo real.
- **Alerta de estoque baixo:** identificação de produtos que atingiram o limite mínimo definido.
- **Resumo do estoque:** contagem de produtos com estoque baixo.
- **Cálculo de valores:** exibição do valor total por produto e do valor total do estoque.
- **Persistência de dados:** utilização do `localStorage` para manter os dados após atualizar a página.
- **Layout responsivo:** adaptação da interface para computadores e dispositivos móveis.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilização dos componentes, cartões, botões e responsividade.
- **JavaScript:** lógica da aplicação, validações, manipulação do DOM e cálculos.
- **localStorage:** armazenamento dos dados no navegador.
- **Git e GitHub:** versionamento e publicação do código-fonte.

## ▶️ Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/KevinMeciasCC/controle-de-estoque.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd controle-de-estoque
   ```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências para executar a aplicação.
