# VEYRA — Inventory Management

**Controle de estoque simples, organizado e intuitivo.**

O **VEYRA** é uma aplicação web desenvolvida para facilitar o gerenciamento de produtos, acompanhar quantidades disponíveis e monitorar níveis mínimos de estoque.

O projeto foi desenvolvido como parte da minha jornada de aprendizado em Engenharia de Software, com foco em desenvolvimento web, JavaScript, manipulação do DOM e persistência de dados.

## ✨ Funcionalidades

- **Cadastro de produtos:** registro de nome, preço e quantidade.
- **Listagem de produtos:** visualização organizada em cartões.
- **Edição de produtos:** atualização de preços e quantidades.
- **Exclusão de produtos:** remoção de itens cadastrados.
- **Pesquisa inteligente:** busca de produtos em tempo real, sem diferenciar letras maiúsculas, minúsculas ou acentos.
- **Controle de estoque mínimo:** definição de limites individuais para cada produto.
- **Alertas de estoque baixo:** identificação visual de produtos que atingiram o limite mínimo.
- **Indicadores:** acompanhamento da quantidade de produtos com estoque baixo.
- **Cálculo de valores:** visualização do valor individual e total do estoque.
- **Persistência de dados:** armazenamento das informações no navegador com `localStorage`.
- **Interface responsiva:** adaptação para computadores e dispositivos móveis.
- **Validação de dados:** prevenção de cadastros e alterações com informações inválidas.

## 💻 Como executar localmente

Não é necessário instalar dependências para executar o projeto.

**1. Clone o repositório:**

```bash
git clone https://github.com/KevinMeciasCC/controle-de-estoque.git
```

**2. Entre na pasta:**

```bash
cd controle-de-estoque
```

**3. Abra o arquivo `index.html` no navegador.**

Você também pode utilizar a extensão Live Server no Visual Studio Code para executar a aplicação durante o desenvolvimento.

## 💾 Armazenamento de dados

Atualmente, o VEYRA utiliza o `localStorage` para armazenar os produtos no próprio navegador.

Isso permite que os dados continuem disponíveis após atualizar ou fechar a página, desde que o armazenamento local não seja apagado.

**Observação:** nesta versão, os dados não são sincronizados entre diferentes dispositivos ou navegadores, pois a aplicação ainda não possui um back-end.
